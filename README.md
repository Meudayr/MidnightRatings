# Percentage Ratings

Converts combat ratings to percentages with a variety of options. Go to the Addons tab in the options menu or type /pr to customize. Compatible with Midnight. Similar to the old Rating Buster or Convert Ratings addons that are depreciated.

Previously known as 'Midnight Ratings'.

Chinese localization done by 枫聖御雷.
